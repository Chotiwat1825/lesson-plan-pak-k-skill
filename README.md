# 🎓 Skill: `lesson-plan-pak-k` — ระบบสร้างและตรวจสอบแผนการจัดการเรียนรู้ ภาค ค (5 หน้า A4)

Skill สำหรับ **Google Antigravity / AI Coding Agent** เพื่อช่วยออกแบบ ปรับปรุง ย่อแผนการสอนเดิม และจัดหน้า **แผนการจัดการเรียนรู้ (1 แผน เวลา 60 นาที ความยาวรวมภาคผนวกไม่เกิน 5 หน้ากระดาษ A4 ฟอนต์ `TH SarabunPSK`)** พร้อมพัฒนาสื่อผสมผสาน (Hybrid Innovation: สื่อ Unplugged + Web App + QR Code สแกนใช้งานได้จริง) สำหรับการประเมิน **ครูผู้ช่วย ภาค ค (สพฐ.)**

---

## ✨ จุดเด่นของ Skill นี้

1. **เน้นถามผู้ใช้วางแผนก่อนลงมือ (`/grill-me` + `/plan`)**:
   - AI จะไม่เขียนแผนมั่วรวดเดียว แต่จะสำรวจไฟล์แผนเดิมในโฟลเดอร์ก่อน แล้ว **สัมภาษณ์ผู้ใช้ทีละข้อ** (เช่น จะสร้างแผนใหม่หรือย่อจากแผนเดิม, รายวิชา/รหัสวิชา/ตัวชี้วัดระหว่างทาง–ปลายทาง, ชื่อครูผู้สอน, ธีมกิจกรรม/สื่อ Web App + QR Code) แล้วสรุปเป็นแผน `implementation_plan.md` ให้ผู้ใช้กดอนุมัติก่อนสร้างไฟล์
2. **อ้างอิงเนื้อหาและช่องไฟจากแผนต้นแบบ (`template_lesson_plan_v3.docx`)**:
   - มีไฟล์ต้นแบบ Word 5 หน้า A4 ที่ปรับจูนช่องไฟ ระยะขอบ การเยื้องย่อหน้า (`Thai Justify`), ตารางหัวแผนไร้กรอบ 2 คอลัมน์พร้อมเส้นคั่น, เส้นประบันทึกหลังสอนแบบ `Tab Stop Dot Leader` ชิดขอบขวาตรงกันทุกบรรทัด, กล่องหัวข้อโค้งมนสีพาสเทลสุภาพ (`#D9E2F3`) และตาราง Scoring Rubric หัวตาราง 2 ชั้นไว้เรียบร้อยแล้ว
   - มาพร้อมฟอนต์ราชการ **`TH SarabunPSK`** (4 น้ำหนัก) และสคริปต์ติดตั้งฟอนต์อัตโนมัติโดยไม่ต้องใช้สิทธิ์ Admin
3. **ตรวจสอบข้อมูล 3 ชั้น (8 จุดวิชาการ + รูปเล่ม 5 หน้า A4 + สื่อดิจิทัล)**:
   - ตรวจความถูกต้องตาม **หลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน พุทธศักราช 2551 (ฉบับปรับปรุง พ.ศ. 2560)**, **หนังสือ สพฐ. ที่ ศธ 04010/ว 1553** (ตัวชี้วัดระหว่างทาง–ปลายทาง), และคำศัพท์มาตรฐาน **สสวท.**
   - ตรวจความครบถ้วนตามเกณฑ์ประเมิน ภาค ค **ข้อ 3.1–3.5** (ครบ 3 ขั้นหลัก: `ขั้นนำเข้าสู่บทเรียน`, `ขั้นการสอน`, `ขั้นสรุป`, คำถามครบ 4 ระดับ + แนวทางตอบสนองผู้เรียนทั้งกรณีตอบถูกและตอบคลาดเคลื่อน, สื่อนวัตกรรม + QR Code, และตารางวัดผล + Rubric ครบ K-P-A และสมรรถนะสำคัญ)
   - แปลงไฟล์ PDF ทั้ง 5 หน้าเป็นภาพ PNG อัตโนมัติเพื่อให้ AI ตรวจสายตาทุกหน้าว่าไม่ล้นไปหน้า 6

## 🚀 วิธีติดตั้ง (สำหรับเพื่อนที่นำไปใช้งาน)

> **ความต้องการของระบบ**: Windows 10/11 ที่มีโปรแกรม **Microsoft Word** และ **Python 3** ติดตั้งอยู่

เปิด **PowerShell** แล้วรันคำสั่งบรรทัดเดียวนี้เพื่อดาวน์โหลดและติดตั้ง Skill พร้อมฟอนต์ `TH SarabunPSK` ลงในเครื่องทันที:

```powershell
git clone https://github.com/Chotiwat1825/lesson-plan-pak-k-skill.git "$HOME\.gemini\config\skills\lesson-plan-pak-k"; powershell -NoProfile -ExecutionPolicy Bypass -File "$HOME\.gemini\config\skills\lesson-plan-pak-k\install.ps1"
```

*(หรือหากดาวน์โหลดเป็นไฟล์ `.zip` มาแตกไฟล์ ให้คลิกขวาเปิด PowerShell ในโฟลเดอร์นั้นแล้วรัน `powershell -ExecutionPolicy Bypass -File .\install.ps1`)*

## 💡 ตัวอย่างคำสั่ง (Prompt) สำหรับสั่ง AI หลังติดตั้งเสร็จ

### กรณีที่ 1: มีไฟล์แผนการสอนเดิม (เช่น 10–15 หน้า) อยากให้ AI ย่อและปรับให้เข้าเกณฑ์ 5 หน้า A4
วางไฟล์แผนเดิม (`.docx` หรือ `.pdf`) และไฟล์รูปสื่อ/เกม (ถ้ามี) ไว้ในโฟลเดอร์ทำงาน แล้วพิมพ์สั่ง:
```text
ใช้ skill lesson-plan-pak-k ช่วยปรับแผนการสอนจากไฟล์แผนเดิมในโฟลเดอร์นี้ ให้เป็นแผน 60 นาที 5 หน้า A4 ตามเกณฑ์ ภาค ค (3.1-3.5) โดยถามฉันเพื่อวางแผนก่อนทำ
```

### กรณีที่ 2: สร้างแผนการจัดการเรียนรู้ฉบับใหม่ + สร้าง Web App และ QR Code จริง
```text
ใช้ skill lesson-plan-pak-k ช่วยทำแผนการจัดการเรียนรู้ สอบภาค ค (1 แผน 60 นาที ไม่เกิน 5 หน้า A4 ฟอนต์ TH SarabunPSK) พร้อมสร้าง Web App และ QR Code ในหน้า 5 โดยสัมภาษณ์ฉันทีละข้อเพื่อวางแผนก่อนลงมือทำ
```

### กรณีที่ 3: ตรวจสอบแผนการสอนที่มีอยู่แล้วตามเกณฑ์หลักสูตรและเกณฑ์ ภาค ค 8 จุด
```text
ใช้ skill lesson-plan-pak-k ช่วยตรวจสอบเนื้อหาและรูปเล่มของแผนการสอนในโฟลเดอร์นี้ตามหลักสูตรแกนกลางฯ 2551 (ปรับปรุง 2560), ว 1553 และเกณฑ์ 3.1-3.5 ทั้ง 8 จุด พร้อมตรวจจำนวนหน้า PDF
```
